What the right-side panel does

Enabled
Untick to mute an event without deleting it. Disabled blocks stay on the timeline as grey placeholders.
Start (ms)
When this voice enters, measured from the top-left of the timeline in milliseconds (1000 ms = 1 s). Blocks may overlap; list order never drives onset — only this number does.
Tempo (tempo_scale)
Reading speed. 1.00 = normal. 0.5 = twice as slow (words stretched, pitch unchanged), 2.0 = twice as fast (compressed, pitch unchanged). Changing it marks the event variant stale — press PREPARE SCORE to hear it.
Gain (dB)
Loudness of this event. 0 = as recorded; −60 … +12. Lower a busy overlap here, not the whole mix.
Pan
Stereo position: −1 = fully left, 0 = centre, +1 = fully right. Use it to separate staggered voices like VOICE-014/015/016.
Pitch (semitones)
Voice character up or down, ±12 semitones. This is the only control that changes who the Voice sounds like.
Reverb
Room feel. 0 = dry and close; 1 = fully wet, distant, hollow. Good for the "body rejecting" passages.
Delay (ms) + Feedback
Echo repeats after the line. Delay sets the gap between repeats (0–2000 ms); Feedback sets how many times it repeats (0–0.95). Keep feedback low unless you want a trance effect.
Attack / Release (ms)
Fade-in and fade-out on this event only. 0 = abrupt. Release also shapes reverb/delay tails, not just the words.
AUDITION EVENT
Plays only this event with all its current settings (auto-prepares if needed).
DUPLICATE / DELETE
DUPLICATE copies line, timing and all processing into a new event. DELETE removes it from the current score; the last saved revision stays recoverable.
Preparing
Any change to these settings makes the processed audio stale until you press PREPARE SCORE in the top bar. Start times and Enabled don't need re-preparing.
