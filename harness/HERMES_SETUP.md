# Hermes entry

Hermes uses progressive-disclosure Skills. This package includes a thin skill at:

`harness/hermes-skill/niravana-voice-prototype/SKILL.md`

Use it by either:
- copying/symlinking the `niravana-voice-prototype` skill folder into the active Hermes skills directory; or
- configuring its parent as an external skill directory.

Then invoke the skill and point Hermes at the repository/workspace containing this package.

The skill does **not** duplicate product or QA authority. It instructs Hermes to read `00_START_HERE.md` and the current task references, use terminal/file tools rather than merely describe work, and update execution state/evidence as it proceeds.
